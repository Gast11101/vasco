# HET CKAMA — Telegram bot

Стартовая версия Telegram-бота на Python + aiogram 3 + SQLite.

## Что уже работает
- Проверка по `@username` или числовому Telegram ID.
- Отправка жалоб пользователями через пошаговый диалог.
- Жалобы попадают в очередь и не видны публично до модерации.
- Главный администратор автоматически закрепляется по username `@ezdelkho`, когда этот аккаунт впервые нажмёт `/start`.
- Одобрение/отклонение жалоб кнопками.
- Статистика и заготовка настроек платного режима.
- SQLite база сохраняется между перезапусками.

## Запуск
1. Установи Python 3.10 или новее.
2. Создай бота через `@BotFather` командой `/newbot`.
3. Скопируй токен в `.env` (создай его копированием `.env.example`).
4. Установи зависимости:
   `pip install -r requirements.txt`
5. Запусти:
   `python bot.py`
6. С аккаунта `@ezdelkho` открой бота и нажми `/start`. Это закрепит числовой Telegram ID владельца в базе.

## Команды
- `/start` — меню
- `/check @username` — проверка
- `/report` — отправить жалобу
- `/pending` — следующая жалоба (админ)
- `/stats` — статистика (админ)
- `/pricing` — состояние заготовки платного режима (админ)

## Важные ограничения текущей версии
- Бот не может сам определить числовой ID произвольного username, если Telegram не передал этот ID. Поэтому поиск по username и ID выполняется по тем значениям, которые были добавлены в жалобах.
- Доказательство пока принимается ссылкой; проверяй доступность и содержание вручную.
- Одобрение означает только результат модерации записи, а не судебно установленный факт. Публикуй только проверяемые фактические сведения, не добавляй лишние персональные данные и обрабатывай запросы на исправление/оспаривание.
- Все проверки сейчас бесплатные. Переключатель оплаты и реальная интеграция платежей ещё не подключены. Перед платным запуском нужно выбрать способ оплаты и реализовать подтверждение платежа на сервере.
- Не добавляй в базу телефоны, адреса, банковские реквизиты, пароли или документы третьих лиц.
